### 总页数公式
```
总页数 = 封面(1) + 台词汇总(约1页) + 去重后台词句数×2(精讲+应用各1) + 重点句型+重点单词(同页，约1页) + 场景练习包(约2~3页)
```

### 小课页面分配（台词句数少时必读，避免孤行页）
- **按台词句数定精讲页策略：**
  - 6句及以下的小课：每句精讲**优先压成1页**，用 `compact-page`（内容多时精简参考答案、适度缩小应用块行距，务必收进一页）
  - 10句+的大课：允许每句1页，必要时合理拆2页（续页顶部空一段、不顶格）
- **铁律：绝不产生孤行页**。若某句内容撑爆页面、最后 Q&A 溢到新一页只剩几行+页脚 → 必须压缩重排回一页，而不是放任孤页
- **参考总页数区间：** 6句课≈8~14页；20句课≈20~24页。超出区间上界往往意味着出现孤行/大空白

### 间距匀称 + 行距舒适规范（以第30课最终版为样板，2026-08-07 定）
> 目标：全篇每部分间距**匀称固定**、每行字**不拥挤**，既不要中间空一大片，也不要挤得像罐头。
- **块间间距匀称且偏小：** 各内容块之间（句子框→句子框架→单词→短语→句型→音变→下一句）间距固定 12~16px，应用页三块（换词/仿写/提问）统一 16px；不拉大、不忽大忽小。
- **行高舒适：** 行高约 1.5~1.6，字距足够，读起来有呼吸感、不拥挤。
- **宁底部空，不中间拉：** 页面底部可自然留白（正常且好看），但绝不在各部分之间用 `space-evenly`/大 margin 硬拉间距去“填满”。想填满就加内容（⭐重点句型速览/核心词汇表），而不是撑间距。
- **处理“一页放不下溢出几行”的三手段（按优先级）：**
  1. 配比：句子长短不一别硬塞“1句=1页”，相邻两句合理分摊，让每页内容量相近（解决有的页挤爆、有的页太空的源头）
  2. 伸缩：上面内容紧凑，空隙全让给页面底部（flex 纵向 + 内容块 flex-start），不把空隙摊到中间
  3. 缩放：只溢出一点点（差2~3行）时，微调该页行高/内边距（mm级）收回去，不动内容
- **验收：** 渲染后逐页默看，要求：无孤行页、无空白页、无“几行字+大片白”的稀疏页、无某页挤爆、无中间硬拉大间距；底部留白无明显离谱的差别。

## 3. 逐句精讲 + 应用

> **去重规则：** 台词汇总页保留全部20句台词（含重复句），但逐句精讲时**相同句子只讲一遍**。
> 例：⑨ 오로라... 和 ⑩ 오로라... 是同一句 → 精讲只做一次，台词汇总里两条都列出来

（每句通常1~2页，精讲下面有空白可合并应用内容；**每个页面尽量排满，不留大片空白**——内容少时可合并相邻内容/适当加大字号间距填满，避免“几行字 + 大片白”的页）

### 3.1 精讲页结构（按此顺序，不可缺项）

```

│  韩文(大号加粗)              │
│  中文(正常)                 │
│  英文(斜体灰)               │
└────────────────────────────┘

┌─ 句子框架 ──────────────────┐
│  🗺️背景 + 👤谁 + 📦什么 + ✍️干（颜色标签） │
│  🔧词尾四种：①②③④             │
└────────────────────────────┘

┌─ 🔊 单句音频（放框架下方） ─┐
│  [点击播放 听这句录音]       │
└────────────────────────────┘

📍 单词（两列grid，韩→中→英）
💬 短语
🔧 句型/接口（通俗易懂的语法讲解，附对应的中文表达）
🎵 音变现象
```

**句子框架写法：**
- **短句**直接标：🗺️背景（有就写，没有就不写）/ 👤谁 / 📦什么 / ✍️干（写原形）/ 🔧词尾（-야지 ①加料 ②接口 ③收尾 ④变身，打钩规则见下方 **3.1.2**）
- **长句（超过7个韩文字）**必拆解，拆解规范见下方 **3.1.2**

**注意：**
- ❌ 不写「跟读三步法」
- ❌ 不用文字描述语音提示（用符号↑↓标注在句子上面：哪里断开、哪里上扬、哪里下降）
- ✅ 🔊 单句音频放在句子框架下方、单词之前
- ❌ 不写"造句"
- ❌ 不写"口语常用"
- ✅ **📍单词 / 💬短语 / 🔧句型 三者严格分开，不得混排**：单词区块只放单词（韩→中→英），短语区块只放固定搭配/惯用语，句型/接口区块只放句型讲解+例句。三块内容各归其位，绝不混在一起

### 3.1.1 句型/接口写法规范（重点）
- ✅ **一个句型一讲**：一条讲解只讲一个句型，不堆叠
- ✅ **通俗易懂的语法讲解**，附上对应的中文表达
- ✅ 讲解内容在句型后面一行，**下面跟两个例句**（生活化、可直接用）

```
🔧 句型/接口：-으면 如果……（如果做某事，就会……）
  讲解：-으면 表示条件，相当于中文的"如果……就……"
  예) 비가 오면 우산을 가져가요.（如果下雨就带伞。）
  예) 시간이 있으면 같이 밥 먹어요.（如果有时间就一起吃饭。）
```

### 3.1.2 长句子拆解规范（重点）

> **判定：** 超过7个音节（韩文字）的句子 = 长句子，必须拆解

**拆解优先级：**
1. **按连接词尾拆**（主）：-고 / -니까 / -는데 / -지만 / -서 等，连接词尾就是短句接缝
2. **标点辅助**（次）：逗号（,）、顿号（/）、句号等天然分界
3. **语义停顿兜底**（末）：读起来自然停顿的地方

**拆解步骤：**
1. **先拆短句** —— 按上面优先级把长句拆成若干短句
2. **逐句分析「谁什么干」** —— 每个短句单独标出：谁（主语）/ 什么（宾语）/ 干（谓语，写原形）
3. **词尾四种形态打钩** —— ①加料 ②接口 ③收尾 ④变身：用到的 ✓ 打钩，没用的整个标签文字中间画删除线。**用到的 ✓ 后面不加任何内容**（不加解释/注释）；**没用到的一律整标签加删除线贯穿**（如 `<s>①加料 —</s>`）
4. **接口分析放两个短句中间** —— 短句与短句之间靠什么连接（连接词尾/助词）

**词尾四种形态定义：**
- **①加料** —— 时态、敬语、补助动词（词尾后面还能加的）
- **②接口** —— 连接句子（连着后面的句子）
- **③收尾** —— 终结一句话
- **④变身** —— 词性变换

**文字型树形图模板：**
```
【长句】그렇지, 정신 차려야지 / 주호진 씨도 일하러 온 건데

┌─ 拆解：①连接词尾（主）②标点（次）③语义停顿（兜底）
│
▼
【短句1】그렇지, 정신 차려야지

 📦什么：无
 ✍️干：정신 차리다（打起精神）← 写原形
 🔧词尾：-야지
   ①加料（时态/敬语/补助动词）✓
   ②接口（连接句子）✓
   ③收尾（终结一句话）✓
   ④变身（词性变换）—

🔗 接口分析（两个短句中间）

 【短句1】-야지 ＋ -도 → 【短句2】-ㄴ 건데

【短句2】주호진 씨도 일하러 온 건데
 🗺️背景：有就写（时间/地点等），没有就不写
 👤谁：주호진 씨
 📦什么：无
 ✍️干：일하러 오다（来工作）← 写原形

   ①加料（时态/敬语/补助动词）—

```

**图标对应：** 🗺️背景 ｜ 👤谁 ｜ 📦什么 ｜ ✍️干 ｜ 🔧词尾

## 4. 末尾固定结构

按以下顺序收尾：

### ① 重点句型（不写"表"字）

| 句型 | 意思 | 本课例句 |
|:----|:----|:--------|
（3~5个核心句型，纯表格不做讲解）

### ② 重点单词（不写"表"字）

| 单词 | 意思 | 联想记忆 |
|:----|:----|:--------|
（5~8个词，联想记忆=反义词/关联词/搭配）

**💡 重点句型+重点单词同页规则：** 重点句型和重点单词**必须放在同一页上**，不要分页，也不要空大片白；重点单词只出现这一次，后面不重复总结单词

### ③ 🎬 场景练习包（放一个页面上）

#### 🗣️ 场景迁移（2个）
**A/B对话型**：两个人一来一回对话（每句标 A/B 角色，像小剧场），剧情连贯（至少4~6轮）。
2个迁移场景放一个页面上。
**每句对话的格式**：对话行的下方，韩文一行 → 中文一行 → 英文一行（三语分行独立，不可挤在一行）。

**🔴 场景对话的灵魂（新增，最重要）：**
场景对话**不是硬凑剧情，而是「把本课的动作/功能用进真实生活场景」**。

- **先定「本课的『动作/功能』」**（不是本课的剧情题材）。例如第30课的剧情是「看极光」，但本课的**功能是「邀请别人」**→ 场景对话就围绕「邀请」这一动作展开，换不同生活场景练。
- **场景可选择任何贴合本课「动作/功能」的生活情境，不局限原剧情、也不限定某一类场景**（邀朋友吃饭、邀看电影、邀旅行、约同事加班、约家人周末活动……都行）。选场景的原则只有一条：**「这个情境最自然地用到本课句型/单词」**。可以是极光剧情本身，也可以是任何合适的生活场景——只要对话自然、覆盖本课知识点即可。
- **一个场景 = 一件具体的小事**（如「邀朋友吃饭→对方推托→我坚持→对方答应」），要有「推进/冲突/结果」，像真聊天，不是各说各的。
- **对话必须自然、有逻辑、每句承上启下、抽出一句也听得懂在干嘛**。绝不允许「为了秀句型硬凑」导致读不懂。
- **本课句型/单词要自然长出**：该场景本来就会用到才用，不是排队打卡硬塞。至少覆盖本课2~3个重点句型 + 3个以上重点单词。
- **两个场景选不同生活情境**（如①请客吃饭 ②邀看电影），围绕同一「动作/功能」练迁移。
示例：
```
🍊 A：다음 달에 여행 가는 김에 같이 가죠!
    下个月既然要去旅行，一起去吧！
    Since we're going on a trip next month, let's go together!
🥝 B：같이 가자고요? 혹시 저한테 부탁할 일 있어요?
    一起吗？难道有事要我帮忙？
    You want me to go? Is there something you need?
```

#### 📝 场景日记 + 🎤 口语挑战（同一页）
**场景日记（5句）：** 5句中文提示，每句下面画两条横线（韩文+英文）。参考答案小字在底部。
**口语挑战：** 不看原文，用今天学的句型说一段30秒的话（自由发挥，不设填空），接在场景日记下方，**与场景日记同页**，不单独分页。

**💡 页面分配建议：** 场景迁移1页 +（场景日记+口语挑战）1页 = 共2页

## 5. 渲染后自检（必做，唯一验收标准）

渲染 PDF 后必须逐页核对，**全部通过才能交付，不给看半成品**：

1. **孤行页检查**：每页内容行要占到页面高度 **≥95%**；出现「只剩几行/仅一个页脚 + 其余全空白」的孤行页 → 必须压缩/合并重排，禁止保留孤页
2. **大面积空白检查**：任何页下半部分不该有大片留白；台词汇总、场景页等若内容不足，按对应章节的「填满手段」补内容
3. **页脚序号检查**：精讲页页脚「台词精讲 X/N」序号完整、无跳号、N 与去重后句数一致
4. **内容完整性检查**：韩中英三语每句都对得上；单词/短语/句型严格分开；词尾四种「用到只✓、没用到删除线贯穿」
5. **页数区间检查**：6句课≈8~14页、20句课≈20~24页；超出上界往往意味着有孤行/大空白
6. **无残留检查**：确认无上一课（如第30课）内容混入本课

> 用 `pdftoppm`/`pdftocairo` 转图逐页查看，或在 HTML 里翻页核对；发现孤行页/空白页就回到对应章节压缩重排（小课优先用 compact-page 收进一页）。
