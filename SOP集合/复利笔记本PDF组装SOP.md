# 复利笔记本PDF组装SOP

> **制作工具：** HTML → Prince/Playwright → PDF
> **参考路径：** 第30课 → `/www/korean_course/E3-30.pdf`（仅作为精讲+应用格式参考）
> **⚠️ 参考PDF不完整**：E3-30.pdf只有封面→台词汇总→精讲→应用，**后面整块没有**。必须按SOP补充以下部分：
> ① 单词汇总（约1页）
> ② 重点句型表（约1页）
> ③ 🎬 场景练习包（场景对话+场景日记，约2~3页）
> **一课规模：** 通常8~15句台词
> **执行顺序：** 录音频 → 封面 → 台词汇总(含整段音频) → 逐句精讲+应用(含单句音频) → 单词汇总 → 重点句型表 → 🎬 场景练习包
> **每课必含：** 跟读(整段+单句) + 仿写 + 场景迁移 + 场景日记

---

## 0. 通用规则（先看！）

### 禁用词 ❌
| 禁用 | 改用 |
|:----|:----|
| 语法 | → 句型/接口 |
| 读音变化 | → 音变现象 |
| 大白话 | → 直译 |

### 风格要素
- 字体：**Noto Sans KR**（韩文）/ **Noto Sans SC**（中文）/ **Noto Sans**（英文）— 三款同族，风格统一，免费开源
- **背景色：浅棕色系** `#faf8f4` → `#f5f0e8` → `#ede6d8` → `#e8dfce`（暖色渐变，参考原版E3-30 PDF的封面风格）
- 深灰字 `#333` / 暖棕标题 `#8b7355`
- 装饰线 `#c4b998`
- 页面底色 `#f8f6f2`（精讲框/图例框/场景对话框）
- 原文顺序：韩文(16px加粗) → 中文(13px) → 英文(11px斜体 #999)
- 每页底部 padding `14mm`
- 每页右上标「台词精讲 X/N」或「台词应用 X/N」
- 标签色：「谁」`#2a6f97`蓝 /「什么」`#2d6a4f`绿 /「干」`#a53860`红

### 总页数公式
```
总页数 = 封面(1) + 台词汇总(约1页) + 去重后台词句数×2(精讲+应用各1) + 单词汇总(约1页) + 重点句型表(约1页) + 场景练习包(约2~3页)
```

## 0.5 🎙️ 音频制作规范（先录制再排版）

### 录音规则
- **音频来源：** 从COS课程视频中提取
- **格式：** MP3 128kbps，单声道
- **保持原声：** 使用原剧演员的台词录音，不替换为AI语音

### 录音内容
- **整段音频：** 本课所有台词按顺序朗读一遍。句间间隔1.5秒
- **单句音频：** 每句台词单独朗读一遍（正常速→慢速）

### 嵌入PDF方式
- 使用 Prince/Playwright 转PDF时，用 `<audio>` 标签嵌入

## 1. 封面 (固定1页)

```
┌──────────────────┐
│  SVG插画(贴合主题) │— 极光/夜空/韩剧氛围，色调统一
│  课名标题(30px)     │— 大号、清晰、暖棕色
│  ── 装饰线 ──      │— 暖金色 #c4b998
│  副标题(16px)       │— 小字优雅
│  一句话简介          │
└──────────────────┘
```

**封面设计要点：**
- 背景：暖沙渐变 `linear-gradient(145deg, #faf8f4, #f5f0e8, #ede6d8, #e8dfce)`
- **SVG插画**要精美、有氛围感（极光/星空/韩剧感），色调与背景统一
- 课号用小字优雅标注，课名标题醒目
- 整体干净、高级、不像廉价模板

## 2. 台词汇总 (1~N页)

```
① 韩文原文
   (English)
   (中文)
② 韩文原文 ...
```

- 全部台词按顺序列出，不去重
- **整段音频放台词汇总页顶部**

---

## 3. 逐句精讲 + 应用

> **去重规则：** 台词汇总页保留全部20句台词（含重复句），但逐句精讲时**相同句子只讲一遍**。
> 例：⑨ 오로라... 和 ⑩ 오로라... 是同一句 → 精讲只做一次，台词汇总里两条都列出来

（每句通常1~2页，精讲下面有空白可合并应用内容）

### 3.1 精讲页结构（按此顺序，不可缺项）

```
┌─ 原文 ─────────────────────┐
│  韩文(大号加粗)              │
│  中文(正常)                 │
│  英文(斜体灰)               │
└────────────────────────────┘

┌─ 句子框架 ──────────────────┐
│  背景 + 谁 + 什么 + 干（颜色标签） │
│  词尾四种：①②③④             │
└────────────────────────────┘

┌─ 🔊 单句音频（放框架下方） ─┐
│  [点击播放 听这句录音]       │
└────────────────────────────┘

📍 单词（两列grid，韩→中→英）
💬 短语
💬 造句
🔧 句型/接口（卡片式，红色标词尾）
💬 句型例句
🎵 音变现象
```

**注意：**
- ❌ 不写「跟读三步法」
- ❌ 不用文字描述语音提示（用符号↑↓标注在句子上面：哪里断开、哪里上扬、哪里下降）
- ✅ 🔊 单句音频放在句子框架下方、单词之前
- ❌ 不写"语法"（写"句型/接口"）
- ❌ 不写"读音变化"（写"音变现象"）

### 3.2 句子框架颜色规则
- 「谁」`#2a6f97`蓝
- 「什么」`#2d6a4f`绿
- 「干」`#a53860`红
- 词尾四种：①加料 ②接口 ③收尾 ④变身（~~没用/✅用到）

### 3.3 单词格式
- 两列grid
- 韩→中→英

### 3.4 应用页结构

```
┌─ 原文回顾 ──────────────────┐
│  (酱色小字居中)              │
└────────────────────────────┘

🔄 换词练习
  格式：标注「在哪换、换的是啥、啥意思」
  例：请把句中的'오로라(极光)'换成'영화(电影)'重新说一遍
  → 答案画横线 __________，小字附参考答案在下面

✍️ 仿写改写
  例：模仿本句句型，写一句你今天想做的事
  → 答案画横线 __________，小字附参考答案在下面

❓ 提问 / Q&A
```

**注意：**
- ❌ 应用页不包含「台词剧场」
- ❌ 应用页不包含「🎭 对话练习」（已移除）
- ✅ 只保留换词练习、仿写改写、Q&A
- ⚠️ 答案不能直接写出来，画横线让读者填，小字附参考答案在下方

## 4. 末尾固定结构

按以下顺序收尾：

### ① 重点句型表

| 句型 | 意思 | 本课例句 |
|:----|:----|:--------|
（3~5个核心句型，纯表格不做讲解）

### ② 重点单词表

| 单词 | 意思 | 联想记忆 |
|:----|:----|:--------|
（5~8个词，联想记忆=反义词/关联词/搭配）

**💡 单词和句型合并规则：** 如果第一页下面还有空白，单词汇总和重点句型表可以合并到一页上，不要空大片白

**注意：** 单词汇总只出现这一次，后面不要重复总结单词

### ③ 🎬 场景练习包（放一个页面上）

#### 🗣️ 场景迁移（2个）
直接韩英中三语对照，**不要中文填空**。
2个迁移场景放一个页面上。

#### 📝 场景日记（单独一个页面）
5句中文提示，每句下面画两条横线（韩文+英文）。
参考答案小字在底部。

**💡 页面分配建议：** 场景迁移1页 + 场景日记1页 = 共2页

```
① 中文句子
_________________________（한국어）
_________________________（English）

② 中文句子
_________________________（한국어）
_________________________（English）
...
⑤ 中文句子
_________________________（한국어）
_________________________（English）
```

**参考答案**放在页面最底部，用小字标注韩→英→中三语。
