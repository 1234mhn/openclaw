# 复利笔记本PDF组装SOP

> **制作工具：** HTML → Prince/Playwright → PDF
> **参考路径：** 现有第28课 → `/www/korean_course/E3-28.pdf` / 第30课 → `/www/korean_course/E3-30.pdf`
> **一课规模：** 通常8~15句台词
> **执行顺序：** 录音频 → 封面 → 台词汇总(含整段音频) → 逐句精讲+应用(含单句音频) → 总复习
> **每课必含：** 跟读(整段+单句) + 对话练习 + 仿写 + 台词剧场

## 0. 通用规则（先看！）

### 禁用词 ❌
| 禁用 | 改用 |
|:----|:----|
| 语法 | → 句型/接口 |
| 读音变化 | → 音变现象 |
| 大白话 | → 直译 |

### 风格要素
- 字体：**Noto Sans KR**（韩文）/ **Noto Sans SC**（中文）/ **Noto Sans**（英文）— 三款同族，风格统一，免费开源
- 白底 `#ffffff` / 深灰字 `#333` / 暖棕标题 `#8b7355`
- 原文顺序：韩文(16px加粗) → 中文(13px) → 英文(11px斜体 #999)
- 每页底部 padding `14mm`
- 每页右上标「台词精讲 X/N」或「台词应用 X/N」
- 标签色：「谁」`#2a6f97`蓝 /「什么」`#2d6a4f`绿 /「干」`#a53860`红

### 总页数公式
```
总页数 = 封面(1) + 台词汇总(约1页) + 去重后台词句数×2(精讲+应用各1) + 台词剧场(约1页) + 总复习(约2页)
       ↑如果台词太多，台词汇总和总复习可扩为多页
       台词剧场与总复习共用页数（单页放不下时合并处理）
```

## 0.5 🎙️ 音频制作规范（先录制再排版）

### 录音规则
- **音频来源：** 从COS课程视频中提取（已有的短视频片段在 `/www/korean_course/videos/` 目录）
  - 整段音频 → 将本课所有视频片段拼起来，统一输出
  - 单句音频 → 从视频中截取该句对应的时间段，单独导出
- **提取工具：** ffmpeg（已有，使用 `ffmpeg -i input.mp4 -vn -acodec libmp3lame output.mp3`）
- **格式：** MP3 128kbps，单声道
- **保持原声：** 使用原剧演员的台词录音，不替换为AI语音，保留语境情感

### 录音内容
- **整段音频：** 本课所有台词按顺序朗读一遍。句间间隔1.5秒，方便跟读
- **单句音频：** 每句台词单独朗读一遍。先读韩文 → 停顿2秒 → 再读一遍韩文
  - 建议两句重复：第一遍正常速→第二遍慢速

### 嵌入PDF方式
- 使用 Prince/Playwright 转PDF时，用 `<audio>` 标签嵌入
- 阅读器：Adobe Acrobat / GoodNotes / 微信读书 均可点击播放

> **参考：** 已有第28课和第30课的音频在 `/www/korean_course/audio/` 目录下

## 3. 逐句精讲 + 应用（每句固定2页）

### 3.1 精讲页结构（按此顺序，不可缺项）

```
① 原文：韩文(16px) → 中文(13px) → 英文(11px斜体)
② 句子框架（见3.3节）— 短句用短句格式，长句用长句格式
③ 单词：两列grid（韩→中→英）
④ 短语：高频搭配 + 说明
⑤ 造句：例句 + 中文翻译
⑥ 句型：卡片式，红色标词尾（不叫"语法"）
⑦ 音变：简洁写，无特殊写"无特殊音变"
⑧ 🎧 单句音频
    每句台词下方嵌入该句的录音（点击播放）
    纸面辅助：断句位置 | 、连读标注（원래→[월래]）

**📖 跟读三步法（写在每课开头或底部提示框）：**
> **① 听一遍** — 不看文字，只听发音和语调
> **② 小声跟** — 看着文字，小声模仿，注意连读
> **③ 凭记忆说** — 遮住文字，凭记忆复述这句
> 全程不追求完美，一句反复3遍即可
⑨ 🎵 语调提示
    全句语调（↗上扬 / ↘下降 / →平稳）
    关键词重音（加粗/划线标注）
    连音位置（台词中的连读标记）
```

### 3.2 应用页结构（四项全含 + 台词剧场）

| # | 内容 | 说明 |
|:---|:----|:----|
| 1 | **🎭 对话练习**（见3.4节） | 用本句单词/句型编1个短对话 |
| 2 | **✍️ 仿写改写**（见3.4节） | 模仿换词 + 半独立写作 |
| 3 | **🔄 换词练习** | 替换关键词/同义词/近义词 |
| 4 | **❓ 提问/Q&A** | 对主语/宾语/时间提问，或一问一答 |
| 5 | **🎬 台词剧场**（见3.6节） | 本课台词串成1~2分钟剧本，分角色读 |

**为什么每句都要有？** 每句台词都是独立的语言点——学了能读（精讲+跟读）→能用（对话）→能变（仿写）→能举一反三（换词+提问）→能演（剧场），一条线打通口语。

> **💡 省力技巧：** 相邻句子的对话练习如果场景相近，可以共享同一个场景，只需换用当前句的单词/句型即可，不必每句都重新编场景。

### 3.3 句子框架模块

拆解句子结构，帮助理解韩语词尾层次。每句台词按以下规则选择格式：

> **短句（≤7韩字）→ 用下方「短句格式」
> 长句（≥8韩字）→ 用下方「长句格式」**

**图例：**
```
🏷️谁     🏷️什么     🏷️干(+词尾动作)
背景(✅可移位)：⏱️时间 📍地点 🔧方式 🎯目的 💡原因 🔄条件 🤝对象

词尾四种：
✅①加料(先语末词尾) — 敬语/时态/推测  -시-/-았-/-겠-
✅②接口(连接词尾) — 连接分句  -고/-지만/-(으)면
✅③收尾(终结词尾) — 结束·敬语·时态·语气  -다/-어요/-ㅂ니다
✅④变身(转性词尾) — 改变词性→修饰/名词/副词  -ㄴ/-는/-기/-게
✅=本句用到  ~~划掉~~=本句没用
```

**格式（短句1~2分句 / 长句多分句）：**
```
+（背景·位置·✅可移位）
+ 🏷️谁（前面可加修饰语）
+ 🏷️什么（前面可加修饰语）
+ 🏷️干（+词尾动作）
    ├─ 原形：
    └─ 词尾：
        ├─ ①加料：
        ├─ ②接口：
        ├─ ③收尾：
        └─ ④变身：
（长句）⬇ 连接关系（如 -고 → 做完A后B）
+ 🏷️干（同上结构）
```

> 完整示例见附录A

### 3.4 对话练习 & 仿写改写（每句必填）

```
🎭 对话练习
角色·语气·情绪标签：
  A — [角色名] — [语气：礼貌/随意/撒娇/生气] 🟢🟡🔴
  B — [角色名] — [语气：礼貌/随意/撒娇/生气] 🟢🟡🔴
场景：(本课相关场景)
A: 韩文
   中文
B: 韩文
   中文
(2~4轮，用本句的核心单词/句型)

✍️ 仿写改写
① 模仿（换1~2个词）：
   原句：__ → 仿写：__
② 半独立（用本句句型写真实情况）：
   中文提示：__ → 你的韩文：__ → 参考：__
③ 自由写（可选）：
   用本句句型写一句你今天想做的事
```

### 3.5 短内容合并规则

- 一句精讲+应用内容不满页面60% → 两句可合并到同一页
- 用浅色分隔线隔开
- 页数按实际占用计算（不是固定×2了）

### 3.6 🎬 台词剧场（每课末尾独立板块）

把本课台词串成1~2分钟短剧本，分角色朗读，全课最后集体开口。

```
🎬 台词剧场 — 本课台词串演

人物：[角色A/角色B/角色C]
时长：约1~2分钟
语气参考：________（整体氛围）

[角色A]（🟢礼貌）：
韩文台词①
→ 中文

[角色B]（🟡随意）：
韩文台词②
→ 中文

[角色A]（🔴焦急）：
韩文台词③
→ 中文

...

🗣️ 单人挑战：选一个角色，独自把整个剧本读一遍，录下来听一遍。
```

**设计规则：**
- 台词按剧中顺序串联，不做大幅改动
- 每句标注角色和情绪（🟢礼貌/🟡随意/🔴生气等）
- 末尾加「单人挑战」——选一个角色独自演完整场
- 如果剧中只有独白，改为单人分角色读

## 附录A：句子框架完整示例

### 短句例：그렇겠죠. → 应该是吧。

```
+ 🏷️谁：(省略)
+ 🏷️什么：(上文内容)
+ 🏷️干：그렇**겠죠**
    ├─ 原形：그렇다
    └─ 词尾：-겠- + -죠
        ├─ ✅①加料：-겠-推测
        ├─ ~~②接口~~
        ├─ ✅③收尾：해요체·现在·确认
        └─ ~~④变身~~
```

### 长句例：방금 ~ 내놓고 ~ 우기다가 ~ 바꾸죠.

```
+（⏱️방금 · 句首 · ✅可移句尾）
+ 🏷️谁：(당신)省略
+ 🏷️什么：말 → "아라고" → "어라고" → "오라고"
+ 🏷️干：내놓**고**
    ├─ 原形：내놓다
    └─ 词尾：-고（并列/先后）
    ⬇ -고(做完A→B)
+ 🏷️干：우기**다가**
    ├─ 原形：우기다
    └─ 词尾：-다가（转换）
    ⬇ -다가(犟着犟着→转)
+ 🏷️干：바꾸**죠**
    ├─ 原形：바꾸다
    └─ 词尾：-죠
        ├─ ✅④收尾：해요체·现在·确认
```
