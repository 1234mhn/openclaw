# 复利笔记本PDF组装SOP

> **制作工具：** HTML → Prince/Playwright → PDF
> **参考路径：** 第30课 → `/www/korean_course/E3-30.pdf` ⚠️ 注意：E3-30.pdf不完整（缺少单词汇总、重点句型表），制作时需按SOP补齐
> **一课规模：** 通常8~15句台词
> **执行顺序：** 录音频 → 封面 → 台词汇总(含整段音频) → 逐句精讲+应用(含单句音频) → 单词汇总 → 重点句型表 → 🎬 场景练习包
> **每课必含：** 跟读(整段+单句) + 仿写 + 场景迁移 + 场景日记

---

## 0. 通用规则（先看！）

### 禁用词 ❌
| 禁用 | 改用 |
|:----|:----|
| 语法 | → 句型/接口 |
| 读音变化 | → 音变现象 |
| 大白话 | → 直译 |

### 风格要素
- 字体：**Noto Sans KR**（韩文）/ **Noto Sans SC**（中文）/ **Noto Sans**（英文）— 三款同族，风格统一，免费开源
- 白底 `#ffffff` / 深灰字 `#333` / 暖棕标题 `#8b7355`
- 原文顺序：韩文(16px加粗) → 中文(13px) → 英文(11px斜体 #999)
- 每页底部 padding `14mm`
- 每页右上标「台词精讲 X/N」或「台词应用 X/N」
- 标签色：「谁」`#2a6f97`蓝 /「什么」`#2d6a4f`绿 /「干」`#a53860`红

### 总页数公式
```
总页数 = 封面(1) + 台词汇总(约1页) + 去重后台词句数×2(精讲+应用各1) + 单词汇总(约1页) + 重点句型表(约1页) + 场景练习包(约2~3页)
```

## 0.5 🎙️ 音频制作规范（先录制再排版）

### 录音规则
- **音频来源：** 从COS课程视频中提取
- **格式：** MP3 128kbps，单声道
- **保持原声：** 使用原剧演员的台词录音，不替换为AI语音

### 录音内容
- **整段音频：** 本课所有台词按顺序朗读一遍。句间间隔1.5秒
- **单句音频：** 每句台词单独朗读一遍（正常速→慢速）

### 嵌入PDF方式
- 使用 Prince/Playwright 转PDF时，用 `<audio>` 标签嵌入

- 背景：暖色渐变 `linear-gradient(145deg, #faf8f4, ..., #e8dfce)`

## 2. 台词汇总 (1~N页)

```
① 韩文原文
   (English)
   (中文)
② 韩文原文 ...
```

- 全部台词按顺序列出，不去重
- **整段音频放台词汇总页顶部**

## 3. 逐句精讲 + 应用（每句固定2页）

### 3.1 精讲页结构（按此顺序，不可缺项）

```
┌─ 原文 ─────────────────────┐
│  韩文(大号加粗)              │
│  中文(正常)                 │
│  英文(斜体灰)               │
└────────────────────────────┘

┌─ 句子框架 ──────────────────┐
│  背景 + 谁 + 什么 + 干（颜色标签） │
│  词尾四种：①②③④             │
└────────────────────────────┘

┌─ 🔊 单句音频（放框架下方） ─┐
│  [点击播放 听这句录音]       │
└────────────────────────────┘

📍 单词（两列grid，韩→中→英）
💬 短语
💬 造句
🔧 句型/接口（卡片式，红色标词尾）
💬 句型例句
🎵 音变现象
```

**注意：**
- ❌ 不写「跟读三步法」
- ❌ 不用文字描述语音提示（用符号↑↓标注在句子上面：哪里断开、哪里上扬、哪里下降）
- ✅ 🔊 单句音频放在句子框架下方、单词之前
- ❌ 不写"语法"（写"句型/接口"）
- ❌ 不写"读音变化"（写"音变现象"）

### 3.2 句子框架颜色规则
- 「谁」`#2a6f97`蓝
- 「什么」`#2d6a4f`绿
- 「干」`#a53860`红
- 词尾四种：①加料 ②接口 ③收尾 ④变身（~~没用/✅用到）

### 3.3 单词格式
- 两列grid
- 韩→中→英

### 3.4 应用页结构

```
┌─ 原文回顾 ──────────────────┐
│  (酱色小字居中)              │
└────────────────────────────┘

🔄 换词练习
✍️ 仿写改写
❓ 提问 / Q&A
```

**注意：**
- ❌ 应用页不包含「台词剧场」
- ❌ 应用页不包含「🎭 对话练习」（已移除）
- ✅ 只保留换词练习、仿写改写、Q&A

## 4. 末尾固定结构

按以下顺序收尾：

### ① 重点句型表

| 句型 | 意思 | 本课例句 |
|:----|:----|:--------|
（3~5个核心句型，纯表格不做讲解）

### ② 重点单词表

| 单词 | 意思 | 联想记忆 |
|:----|:----|:--------|
（5~8个词，联想记忆=反义词/关联词/搭配）

### ③ 🎬 场景练习包

#### 🗣️ 场景对话
根据本课场景编一个小对话，**只有中文**，下面画横线让读者填韩文和英文：

```
A: （中文句子）
_________________________（한국어）
_________________________（English）

B: （中文句子）
_________________________（한국어）
_________________________（English）

A: （中文句子）
_________________________（한국어）
_________________________（English）

...
```

**参考答案**放在页面最底部，用小字标注韩英对照。

#### 🔄 场景迁移（可选）
用本课句型+词汇，把当前场景迁移到另一个类似场景。

#### 📝 场景日记 · 填空练习
用本课句型写5句真实生活场景日记，**只有中文**提示，下面画两条横线分别写韩文和英文：

```
① 中文句子
_________________________（한국어）
_________________________（English）

② 中文句子
_________________________（한국어）
_________________________（English）
...
⑤ 中文句子
_________________________（한국어）
_________________________（English）
```

**参考答案**放在页面最底部，用小字标注韩→英→中三语。
