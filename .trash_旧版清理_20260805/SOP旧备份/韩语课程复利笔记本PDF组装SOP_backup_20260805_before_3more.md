## 3. 逐句精讲 + 应用

> **去重规则：** 台词汇总页保留全部20句台词（含重复句），但逐句精讲时**相同句子只讲一遍**。
> 例：⑨ 오로라... 和 ⑩ 오로라... 是同一句 → 精讲只做一次，台词汇总里两条都列出来

（每句通常1~2页，精讲下面有空白可合并应用内容）

### 3.1 精讲页结构（按此顺序，不可缺项）

```
┌─ 原文 ─────────────────────┐
│  韩文(大号加粗)              │
│  中文(正常)                 │
│  英文(斜体灰)               │
└────────────────────────────┘

┌─ 句子框架 ──────────────────┐
│  🗺️背景 + 👤谁 + 📦什么 + ✍️干（颜色标签） │
│  🔧词尾四种：①②③④             │
└────────────────────────────┘

┌─ 🔊 单句音频（放框架下方） ─┐
│  [点击播放 听这句录音]       │
└────────────────────────────┘

📍 单词（两列grid，韩→中→英）
💬 短语
🔧 句型/接口（通俗易懂的语法讲解，附对应的中文表达）
🎵 音变现象
```

**句子框架写法：**
- **短句**直接标：🗺️背景（有就写，没有就不写）/ 👤谁 / 📦什么 / ✍️干（写原形）/ 🔧词尾（-야지 ①加料✓ ②接口✓ ③收尾✓ ④变身—）
- **长句（超过7个韩文字）**必拆解，拆解规范见下方 **3.1.2**

**注意：**
- ❌ 不写「跟读三步法」
- ❌ 不用文字描述语音提示（用符号↑↓标注在句子上面：哪里断开、哪里上扬、哪里下降）
- ✅ 🔊 单句音频放在句子框架下方、单词之前
- ❌ 不写"语法"（写"句型/接口"）
- ❌ 不写"读音变化"（写"音变现象"）
- ❌ 不写"造句"
- ❌ 不写"口语常用"
- ✅ **📍单词 / 💬短语 / 🔧句型 三者严格分开，不得混排**：单词区块只放单词（韩→中→英），短语区块只放固定搭配/惯用语，句型/接口区块只放句型讲解+例句。三块内容各归其位，绝不混在一起

### 3.1.1 句型/接口写法规范（重点）
- ✅ **一个句型一讲**：一条讲解只讲一个句型，不堆叠
- ✅ **通俗易懂的语法讲解**，附上对应的中文表达
- ✅ 讲解内容在句型后面一行，**下面跟两个例句**（生活化、可直接用）

```
🔧 句型/接口：-으면 如果……（如果做某事，就会……）
  讲解：-으면 表示条件，相当于中文的"如果……就……"
  예) 비가 오면 우산을 가져가요.（如果下雨就带伞。）
  예) 시간이 있으면 같이 밥 먹어요.（如果有时间就一起吃饭。）
```

### 3.1.2 长句子拆解规范（重点）

> **判定：** 超过7个音节（韩文字）的句子 = 长句子，必须拆解

**拆解优先级：**
1. **按连接词尾拆**（主）：-고 / -니까 / -는데 / -지만 / -서 等，连接词尾就是短句接缝
2. **标点辅助**（次）：逗号（,）、顿号（/）、句号等天然分界
3. **语义停顿兜底**（末）：读起来自然停顿的地方

**拆解步骤：**
1. **先拆短句** —— 按上面优先级把长句拆成若干短句
2. **逐句分析「谁什么干」** —— 每个短句单独标出：谁（主语）/ 什么（宾语）/ 干（谓语，写原形）
3. **词尾四种形态打钩** —— ①加料 ②接口 ③收尾 ④变身：用到的 ✓ 打钩，没用的 — 画横线
4. **接口分析放两个短句中间** —— 短句与短句之间靠什么连接（连接词尾/助词）

**词尾四种形态定义：**
- **①加料** —— 时态、敬语、补助动词（词尾后面还能加的）
- **②接口** —— 连接句子（连着后面的句子）
- **③收尾** —— 终结一句话
- **④变身** —— 词性变换

**文字型树形图模板：**
```
【长句】그렇지, 정신 차려야지 / 주호진 씨도 일하러 온 건데

┌─ 拆解：①连接词尾（主）②标点（次）③语义停顿（兜底）
│
▼
【短句1】그렇지, 정신 차려야지
 🗺️背景：有就写（时间/地点等），没有就不写
 👤谁：省略 / 说话人自己
 📦什么：无
 ✍️干：정신 차리다（打起精神）← 写原形
 🔧词尾：-야지
   ①加料（时态/敬语/补助动词）✓
   ②接口（连接句子）✓
   ③收尾（终结一句话）✓
   ④变身（词性变换）—

🔗 接口分析（两个短句中间）
 -도（也）连接两个短句
 【短句1】-야지 ＋ -도 → 【短句2】-ㄴ 건데

【短句2】주호진 씨도 일하러 온 건데
 🗺️背景：有就写（时间/地点等），没有就不写
 👤谁：주호진 씨
 📦什么：无
 ✍️干：일하러 오다（来工作）← 写原形
 🔧词尾：-ㄴ 건데
   ①加料（时态/敬语/补助动词）—
   ②接口（连接句子）✓
   ③收尾（终结一句话）✓
   ④变身（词性变换）—
```

**图标对应：** 🗺️背景 ｜ 👤谁 ｜ 📦什么 ｜ ✍️干 ｜ 🔧词尾

**格式规则：** 同台词汇总（三行独立，韩→中→英）

#### 📝 场景日记（单独一个页面）
5句中文提示，每句下面画两条横线（韩文+英文）。

**💡 页面分配建议：** 场景迁移1页 + 场景日记1页 = 共2页
