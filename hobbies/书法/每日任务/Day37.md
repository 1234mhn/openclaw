# 🖌️ 书法练习 · 第37天

> 荆霄鹏《通用规范7000字·楷书》— 半包围结构

---

## 🏋️ 控笔训练（5min）

**① "┌"形折线 × 10个**
- 模拟左上包围的轮廓线
- 横→折→竖，转角方正
- 节奏：先横再折转下行

**② 右上开口 × 10个**
- ┐ 形开口框
- 模拟右上开口的包围结构（如"可""式"）
- 左竖短、上横长，注意左低右高

---

## 🖌️ 例字练习

### 左上包围：「原」「居」「病」「庆」
**每字写6遍**

```
原 — 厂字头撇画舒展，"白+小"要居右偏外
居 — 尸字头左上包，底部"古"对齐不内缩
病 — 病字头两点靠左，内部"丙"不要完全藏在里面
庆 — 广字头撇舒展，"大"字撇捺打开
```

### 右上包围：「可」「或」「式」
**每字写6遍**

```
可 — "丁"部钩底要平，口部偏左出外（右上开口）
或 — 戈钩斜中带挺，口部偏左不可居中
式 — 工部偏左，斜钩要长挺有力
```

### 全包围过渡：「庭」
**写6遍**

```
庭 — 广字头（左上包围变体），内部"廷"笔画紧凑
      注意捺画舒展，不要缩在字头里
```

---

## 💡 要点提醒

1. **半包围结构的关键** — 被包部分不能完全缩在里面，要"偏外"（视觉上偏右或偏下）
2. **左上包围**（原/居/病/庆）— 字头要盖得住，内部靠外
3. **右上包围**（可/或/式）— 内部偏左，不能居中
4. **写完一个字退一步看** — 整体轮廓对不对？被包部分有没有太靠里？

---

## ⚠️ 今天特别注意

> **被包部分别缩进去！** — 半包围常见的错误就是把里面写太靠里

- **"原"字的"白+小"** — 要感觉快要从左边冒出来
- **"可"字的"口"** — 不要藏在横和钩的中间，要偏左位
- **"庆"字的"大"** — 撇捺打开，别被上面广字头压住

**之前日记提到的"冶字底部口写太方"（Day 20）同样适用于今天的"可"字里的"口"— 口要扁平！**
