# 📋 日常口语表达积累 · 分类规范

> 用户随手发来好短语/句型/表达 → 自动归类归档 → 每次回一个例句巩固

## 类型标签
- 🟢 **短语** — 固定搭配（run out of / take it easy）
- 🟡 **句型** — 可替换框架、特殊用法（It's worth doing… / It takes…to…）
- 🔵 **单词/表达** — 地道词汇、俚语
- 🟠 **场景用语** — 点餐/购物/职场/旅行/情绪等，附具体场景

> 每次归档后，都会附上该表达**适用场景**。

## 每周总结
- **每周自动汇总**：把本周积累的表达按场景归类，合并到一份「周总结」里
- 例：打招呼/自我介绍、工作/职场、情绪/感受、吃饭/聚会…… 同场景放一起，方便集中复习

## 归档格式（每条一条，按日期分组）
```
### 📅 YYYY-MM-DD
- **表达**：[英文原句/短语]
- **类型**：🟡 句型
- **中文**：[中文翻译]
- **场景**：[适用场景]
- **用法**：[关键用法/音变/替换点]
```

## 文件组织
- 主索引：`日常口语表达索引.md`（全部表达汇总表）
- 明细：按日期或按类型分文件（如遇量大自动拆分）
