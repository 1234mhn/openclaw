# 楷书结构复盘 · 2026.07.31

## 一、左右结构

| 字 | 关键点 | 易错 |
|---|---|---|
| 料 | 左右高度一致，右边"斗"不过高 | 右部写太高 |
| 粉 | 右边"分"收紧，撇捺不外张过大 | 撇捺太开 |
| 粘 | 右侧"占"的口写扁，不写大 | 口写太方太大 |
| 狗 | 反犬弯钩弧度别太大；右边"句"的口往上靠 | 口往下坠 |
| 亿 | 右边"乙"转弯要圆润，不能写成硬尖角 | 转折太硬 |

## 二、宝盖/广字头

> **核心：盖子要包住里面**

| 字 | 关键点 |
|---|---|
| 庆 | 广字头里面的"大"收窄，捺不能伸到外面 |
| 罕 | 宝盖写宽盖住下方，下面不写太宽 |
| 冤 | 内部"兔"收紧，宝盖放宽兜住下方 |
| 宝 | 玉的点写在王字内部右下，不能写到右上角外面 |

## 三、上下/多层堆叠

| 字 | 关键点 |
|---|---|
| 冥 | 部件多，整体压扁，不要纵向拉长 |

## 四、独体字

| 字 | 关键点 |
|---|---|
| 也 | 竖弯钩弧度平缓，勾短小有力，不要画大圆 |
| 丈 | 捺适度舒展，不过度放开 |
| 之 | 点和横撇不要粘在一起；捺平着出，不要向上翘 |

## 五、核心原则提炼

1. **左右字** → 两边尽量等高
2. **带盖子字头** → 盖子要宽，包住内部
3. **独体字** → 主笔舒展，其余部件收紧

---

## 练习感悟

- 今天覆盖了四大结构类型，左右结构练得最多（5个字）
- "粘""狗"是容易整体失衡的字，需要特别注意比例
- "宝"的点位置是小细节，但楷书最吃细节
- 宝盖头的核心逻辑：盖不住内部 = 字散了
- 独体字三个都带出锋笔画（竖弯钩、捺），出锋是重点
