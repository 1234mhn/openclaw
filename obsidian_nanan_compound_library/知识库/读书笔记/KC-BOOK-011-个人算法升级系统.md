## 💡 核心洞察（一句话）

**把你的学习和赚钱当作一套算法来运行：自知缺陷 → 自学录入 → 迭代修正，每天跑一圈，一年后效果>1。**

> 如果理解是对的，口袋里早该有了。——《价值心法》

## 📐 行动指南

### 三大基础算法流水线

```
算法一：自知 ────→ 算法二：自学 ────→ 算法三：迭代
(问"我卡在哪")    (任何技能都能练)     (发现问题→解决它)
      ↓                  ↓                  ↓
   找到缺陷          输入+加工+输出      跑完一轮再升级
```

**算法一：自知（看清缺陷在哪）**

每天睡前问自己一个问题：
> 我今天离"口袋里有我想要的东西"还差在哪一步？
- 是学错东西了？ → 回去跑变现三问
- 是东西对了但没打包？ → 想怎么包装成可交付的
- 是挂上去了但没人问？ → 迭代描述和定价

**算法二：自学（任何技能都能用算法练）**

你会的任何一项技能——韩语、写作、AI、剪辑——都是通过这个算法练出来的。赚钱也一样。

```
Input（学一个概念/看一个案例）
  ↓
Process（写卡片/复盘/内化）
  ↓
Output（最小交付：发笔记/挂闲鱼/开一单）
```

不需要新的天赋，只需要**跑通这条流水线**。

**算法三：迭代（在实现过程中找问题）**

```
第1版 → 没人买？
  ↓
找问题：描述不清楚？价格不对？人群不对？
  ↓
改 → 第2版再挂
  ↓
又发现问题 → 再改 → 第3版
```

每改一次，你的"算法"就升级一个版本。你不是在卖笔记——你是在**用卖笔记这件事训练自己的赚钱算法**。

### 复利公式

> **每天进步 1% → 1年后效果 ≈ 37.8 倍**
>
> 1.01³⁶⁵ ≈ 37.8

你今天挂闲鱼、想定价、问"300粉行不行"——这些动作每一个都在升级你的算法。一年后回来看，那个跑了365轮算法的你，跟站在起点不动的人，完全是两个物种。

## 🟢 绿灯（适用场景）

- 学了很久但口袋还是空的，想系统性解决问题
- 新学了一个技能，想知道怎么让它"生钱"
- 已经在做（挂闲鱼/发笔记），但不知道怎么持续优化
- 感觉自己卡住了，需要一个框架来诊断"卡在哪"

## 🔴 红灯（不适用场景）

- 你已经在跑自己的系统且效果稳定（不需要新框架来干扰）
- 你只是需要解决一个具体技术问题（比如"怎么写闲鱼标题"——该去学具体技能，不是跑算法）
- 你处于纯粹的放松/消遣状态（不用每件事都算法化）
