# 🔥 语言知识回炉重造（语言版 · v1）

> **核心理念：** 学语言的核心是「迁移能力」——读懂≠会，**能用学过的句型/单词造出新句子＝真会**（产出性运用）。
> **适用范围：** 英语库 + 韩语库 的全部语言学习内容（口语复盘、台词复利笔记、词汇、句型等）
> **核心机制：** 按场景复习 + 聚焦2个重要句型+常用单词 + 费曼迁移 + 间隔重复 + 五维检验 + 盲区追踪 + 触发合约
> **🔴 铁律：上午学的语言内容，晚上必须复盘，当日事当日毕！**

> ✅ AI/ML 内容走《知识回炉重造》（原AI版）。本文件专管**语言**。

## 〇、触发合约（治"没人触发，机制失效"）

**用户开口说话（任何话题），先检查状态文件 `nextReview` 列表：**

```
1. nextReview 到期 且 当前时间 ≥ 18:00 → 先点名复盘（最多3个），再聊用户想聊的
2. 用户学完英语/韩语内容（口语对话/台词课/词汇）→ 判断是否学完，学完即录
3. 都没有 → 正常对话
```

> 「📋 对了，昨天『买火车票』那个场景今天到期了——用两个新句子说说怎么买票？说完了咱再聊别的。」

### 免打扰窗口（白天不打断）

- **白天（<18:00）**：只做录入检查，不触发复盘点名——用户聊别的正常聊，不被插题
- **晚上（≥18:00）**：nextReview 到期的才点名复盘
- **紧急例外**：用户明确说"紧急/先处理这个" → 复盘后移，不强插

### 录入触发（跨session防漏）

**AI 检测到语言学习内容结束时，主动询问录入，不等用户说：**

> 「刚学的『买火车票』场景要不要录进追踪？我建议录（L2，7天后复习）。」

- 即使换了 session，对话中出现语言学习内容 → 默认走"学完即录"
- 用户说"不用录"才跳过，默认动作是**录**

## 一、防漏机制（治"学了就丢"）

### 环节① 录入 —— 强制"学完即录"

- 学完一个场景/一课 → **当场录入状态文件** + 告知用户：「已录入：买火车票（L2，下次复习7天后）」
- 状态文件 `pendingEntry` 字段：当天有学习但没录入时留"未入账"标记
- 每晚检查发现标记 → 必须补录或说明原因

### 环节② 触发 —— 触发合约（见上）

`nextReview` 日期就是待办清单，晚上开口就查。

### 环节③ 执行 —— 当日事当日毕（铁律）

- **🔴 上午学的语言内容，晚上必须复盘**，不拖到第二天
- 每晚最多复盘3个（新学1-2个 + 到期旧场景1-2个）
- 复盘完**当场更新状态**（掌握度/下次复盘日/检验维度），不留"明天再说"
- **简单复盘最低更新要求**：至少更新3个字段——`level`、`nextReview`、`lastTest`
- **`reviewCount` 每次复盘后 +1**

### 环节④ 审计 —— 每周日自动清点

- 每周日晚生成**周复盘清单**，存 `memory/lang-review-weekly.md`：
  ```
  本周应复盘：8个 → 实际复盘：6个 → 漏2个（下周优先）
  本周新增：2个
  追踪总数：15个 | L3以上：5个 | 需加强：4个
  盲区清单：2个（已优先安排）
  ```
- **漏掉的卡片下周自动排最前面**

## 二、间隔重复（治"忘"）

### 排期规则（唯一出口）

每个语言场景/句型按记忆曲线安排复盘：

```
学完 → 1天后 → 3天后 → 7天后 → 15天后 → 30天后
```

**下次复盘间隔由上次表现决定（此处为唯一标准）：**

| 上次表现 | 下次间隔 |
|:---------|:---------|
| 造不出句子/卡壳（含提示走完仍卡） | 3天后（降级重学） |
| 造句流畅但没换新场景 | 7天后 |
| 流畅 + 现场换新场景造了新句 | 15天后 |
| 费曼迁移过关（三条全过） | 30天后 |

- 当天没有新学内容 → 只复盘到期的旧场景
- 某场景**连续2次卡壳** → 降级重学，先搞懂再往前学，进盲区
- 已掌握（L4）的场景 → 偶尔抽查

## 三、场景复盘法（按场景复习 · 核心）

> **昨天定下的核心方法：** 每次挑一个场景（如"买火车票"），聚焦该场景下 **2个重要句型 + 常用单词**。

### 复盘对象（从状态文件 cards 取，每个卡片=一个场景）

每个场景卡片存：
- 场景名 + 语言（英语/韩语）+ 场景标签（如 🚄出行 🎫购票）
- 2个重要句型（本场景的万能句型/核心语法）
- 常用单词清单（本场景高频词）
- 原句/台词（本场景出现的典型句子，供回看）
- 关键表达 多种说法 / 中式避雷（如有，韩语为"用法避雷"）

### 复盘流程（5步）

**预热：我先说这个场景我会怎么表达**

我先用通俗的话/正确句子，把"这个场景该怎么说"演示一遍，给你打个样。

> 例 — 买火车票（英语）：「我会说 If you want to buy a train ticket online, first open the app, then type your starting place and destination.」

**第一步：你用这个场景造2个新句子**

- 用该场景的 **2个重要句型**，各造1个新句子（**必须换词/换场景，不能背笔记原句**）
- 能现场造新句 = 真会；只能背原句 = 还没消化

> 「别用笔记里的『open the app』，用同一个句型『If you want to…, you can do it in a few easy steps』换个事试试。」

**第二步：费曼迁移——你教我（治"浅"的核心）**

- 我扮演完全不熟的人，问你：「这个句型在什么情况下能用？什么情况下不能？」
- 追问必须是 **Why类 或 边界类**问题（为什么这么用？什么场景不适用？），**禁止复述题**
- **强制换场景造新例**：每个句型必须给一个**笔记里没有的**新场景例子
  - 能现场换场景造新例 = 真懂
  - 只能背笔记例子 = 还没消化

### 费曼迁移过关标准（结构化，防主观放水）

**L4/过关必须三条全满足：**

```
① 用自己的话说出句型/表达
② 换了场景造了新句子（笔记外）
③ 回答了我至少一个 Why类/边界类 追问
```

三条全过 = 过关 → 30天后复盘
缺任何一条 = 不算过关 → 按表现降级排期

### 提示梯子（卡住时的引导，按顺序走，不跳级）

```
正常检验 → 用户说不出新场景的新句子 → 提示1（生活类比：什么时候会用到这个句型？）
提示1给完仍卡                         → 提示2（换个场景：在饭店/机场怎么套用？）
提示2给完仍卡                         → 提示3（半句话开头）
提示3给完仍卡                         → 提示4（直接示范 + 记入盲区 + 3天后必回）
```

> 例 — 韩语 `-고 싶다` 卡住：
> 提示1：「想想你平时想做什么事，怎么跟人说？」→ 想看剧/想吃炸鸡
> 提示2：「换成『想去旅行』『想吃拌饭』，怎么说？」
> 提示3：「나 ____고 싶어요…」
> 提示4：直接示范「보고 싶어요. 먹고 싶어요.」，标记「需加强」，3天后必回

**第三步：串联旧知识**

把你新学的场景和之前学过的场景/句型连起来，形成语言网络。

> 「这个『in a few easy steps』跟你上次学的『with just a few taps』有什么差别？」
> 「韩语这个动词이렇게 활용，跟咱们之前学的过去式连用会有变化吗？」

**第四步：一起深挖**

不只我问你答，咱俩一起往深处挖。

> 「这个句型在口语里还能怎么缩？跟书面语差别大吗？」
> 「韩国人日常真这么说，还是课本才这么讲？」

## 四、五维检验（治"虚"）

每次复盘随机抽**一种或多种**方式检验：

| 维度 | 检验方式 | 过关标准 |
|:----:|:---------|:---------|
| **说** | 复述该场景的句型/表达 | 不磕巴、不用笔记 |
| **用** | 现场换新场景造句子 | 句子是新造的，不是背的 |
| **联** | 跟之前学过的句型/场景连起来 | 能说出共同点和差异 |
| **做** | 仿写/翻译验证 | 能造对、能中译外 |
| **教** | 费曼迁移（见三步第二步） | 三条全过 |

> **防重复：** 单张卡片最近2次 `lastTest` 不能相同——至少隔一轮才能重复同一维度。

## 五、掌握度追踪系统

### 掌握度等级

| 等级 | 含义 | 判断标准 |
|:----:|:----|:---------|
| **L1 初识** | 听过，说不出 | 提示梯子走完仍答不上来 |
| **L2 理解** | 能用自己的话讲清楚 | 能回答"是什么"和"为什么" |
| **L3 应用** | 能换场景造句 | 通过"用/做"维度检验 |
| **L4 内化** | 费曼迁移过关（三条全过） | 说+新例+答Why/边界追问 |

> 升级/降级动作：按「间隔重复」表执行（卡壳→降级3天，过关→升级30天）。
> **升级时**：AI 主动问「这个句型你现在的一句话概括是？」，更新 `keyInsight`。

### 盲区（治"漏"）—— 卡片内 `blindSpots` 字段

- 说不清、卡壳的点 → 记入卡片内 `blindSpots`
- **连续2次卡壳 → 降级重学**，不硬往前赶
- **`blindSpots` 不为空的卡片 → 每次复盘优先抽**
- **提示走完仍卡 → 记入 `blindSpots` + 3天后必回**

### 个人易错画像（治"重复错"）

- 积累高频错误类型，形成画像：
  ```
  你的高频错误：句型混淆 40% / 中式直译 25% / 词形变化 20% / 场景误用 15%
  ```
- 下次复盘优先抽最容易错的知识类型

## 六、双向复盘原则

- 复盘不是考试，是对话
- 我也会分享更好的表达：「其实"in a few easy steps"也可以说"in just a few taps"」「韩国人日常更常说这个」
- 发现你中式直译/韩语敬语混搭 → 我会提出来
- 我也不确定 → 说"这个我也不太确定，咱们一起查查"

## 七、复盘记录（分轻重）

### 触发条件

```
发现盲区 或 费曼迁移过关（三条全过） 或 产生了有价值的新串联/深挖结论 → 深度记录
其余情况（说/用/联/做 过关）                                          → 简单更新
```

### 简单复盘 —— 轻量更新

只更新状态文件，**至少3个字段**：`level`、`nextReview`、`lastTest`（`reviewCount` +1）。

### 深度复盘 —— 完整记录

在对应语言卡片末尾追加：

```
---
🔄 复盘记录（第X轮 YYYY-MM-DD | 语言：英语/韩语 | 场景：XXX）

一句话概括：XXX
检验维度：说/用/联/做/教（本次用的）
费曼过关：是/否（三条全过）
追问点：XXX（须为Why/边界类）
串联：与XXX关联
深挖：讨论了XXX

掌握度：L2→L3（提升一级）
下次复盘：YYYY-MM-DD（按间隔规则）

盲区记录：XXX（若有）
我的补充：楠楠分享了XXX看法
---
```
