# 🔥 知识回炉重造（优化版 v6 · 定稿）

> **核心理念：** 不考记忆，考理解。复盘是对话，不是考试。
> **适用范围：** 仅限 AI / 机器学习 / 深度学习 相关内容
> **核心机制：** 费曼教学法 + 间隔重复 + 五维检验 + 盲区追踪 + 防漏审计 + 触发合约
> **🔴 铁律：上午学的内容，晚上必须复盘，当日事当日毕！**

> ⚠️ 注意：英语口语、韩语等非AI内容**不纳入本体系**，各自走自己的复盘流程。

---

## 〇、触发合约（最重要！治"没人触发"）

> 之前的问题：假设"晚上8点自动点名"，但定时推送不可靠——没人触发，机制就失效。
> 现在：把触发**嵌入每一次对话**，不靠假设。

### 触发规则（硬合约）

**用户开口说话（任何话题），先检查状态文件 `nextReview` 列表：**

```
1. nextReview 到期 且 当前时间 ≥ 18:00 → 先点名复习（最多3个），再聊用户想聊的
2. 用户提到了 AI/ML 学习内容 → 判断是否学完，学完即录
3. 都没有 → 正常对话
```

> 「📋 对了，KNN 今天到期了（L2）——用一个新例子说说它怎么分类？说完了咱再聊别的。」

### 免打扰窗口（白天不打断）

- **白天（<18:00）**：只做录入检查，不触发复盘点名——用户聊别的正常聊，不被插题
- **晚上（≥18:00）**：nextReview 到期的才点名复习，符合"晚上复盘"铁律
- **紧急例外**：用户明确说"紧急/先处理这个/帮我debug"→ 复盘后移，不强插

### 录入触发（跨session防漏）

**AI 检测到 AI/ML 学习内容结束时，主动询问录入，不等用户说：**

> 「刚学的 CLIP 要不要录进追踪系统？我建议录（L2，7天后复习）。」

- 即使换了 session，对话中出现 AI/ML 学习内容 → 默认走"学完即录"流程
- 用户说"不用录"才跳过，默认动作是**录**

## 一、防漏机制（治"学了就丢"）

### 环节① 录入 —— 强制"学完即录"

- 学完新AI知识 → **当场录入状态文件** + 告知用户：「已录入：XXX（L2，下次复习7天后）」
- 状态文件 `pendingEntry` 字段：当天有学习但没录入时留"未入账"标记
- 每晚检查发现标记 → 必须补录或说明原因

### 环节② 触发 —— 触发合约（见上）

`nextReview` 日期就是待办清单，晚上开口就查。

### 环节③ 执行 —— 当日事当日毕（铁律）

- **🔴 上午学的AI内容，晚上必须复盘**，不拖到第二天
- 每晚最多复习3个（新学1-2个 + 到期旧知识1-2个）
- 复习完**当场更新状态**（掌握度/下次复习日/检验维度），不留"明天再说"
- **简单复盘最低更新要求**：至少更新3个字段——`level`、`nextReview`、`lastTest`，缺一不可
- **`reviewCount` 每次复盘后 +1**（防僵尸字段）

### 环节④ 审计 —— 每周日自动清点

- 每周日晚生成**周复盘清单**，存 `memory/ai-review-weekly.md`：
  ```
  本周应复习：8个 → 实际复习：6个 → 漏2个（下周优先）
  本周新增：2个
  追踪总数：15个 | L3以上：5个 | 需加强：4个
  盲区清单：2个（已优先安排）
  ```
- **漏掉的卡片下周自动排最前面**

## 二、间隔重复（治"忘"）

### 排期规则（唯一出口）

每个AI知识点按艾宾浩斯曲线安排复习：

```
学完 → 1天后 → 3天后 → 7天后 → 15天后 → 30天后
```

**下次复习间隔由上次表现决定（此处为唯一标准，掌握度表不重复写天数）：**

| 上次表现 | 下次间隔 |
|:---------|:---------|
| 讲得磕巴/说不出（含提示梯子走完仍卡） | 3天后（降级重学） |
| 讲得流畅但没举新例 | 7天后 |
| 流畅 + 现场举了新例 | 15天后 |
| 费曼过关（结构化三条全过） | 30天后 |

- 当天没有新学内容 → 只复盘到期的旧知识
- 某知识点**连续2次卡壳** → 降级重学，先搞懂再往前学，进盲区（统一规则，无"3次"说法）
- 已掌握（L4）的知识点 → 偶尔抽查

## 三、五步复盘法（费曼升级版）

### 预热：我先说说我的理解

我先用通俗的话把这个AI知识点讲一遍，给你打个样。

> **例 — 线性回归：**
> 「我理解的线性回归，就是找一条直线，让它尽可能穿过所有的数据点。
> 如果穿不过去，就让它离所有点的总距离最近。
> 这条直线的公式就是 y = ax + b，机器学习做的就是找到最合适的 a 和 b。」

> **例 — 损失函数：**
> 「损失函数就像一把尺子，量一量模型预测得到底准不准。
> 预测越不准，这把尺子的读数就越大。
> 模型训练的目标就是让这把尺子的读数越来越小。」

### 第一步：你用一句话说清

用你自己的话，**一句话**说清楚这个知识点是什么。不用术语，就像跟朋友解释一样。

> 「线性回归就是……」
> 「损失函数就是……」

### 第二步：费曼教学——你教会我（治"浅"的核心）

讲完概念后，**你当老师，我当完全不懂的学生**：

- 我扮演外行，专门挑刺提问：「等等，这里我没听懂，为什么是这样？」
- **追问必须是 "Why类"或"边界类"问题**（为什么这样设计？什么情况下不适用？），**禁止问复述题**（如"你刚才说的是什么"）——防止AI出简单题放水
- **强制出新例子**：每个概念必须给一个**笔记里没有的**新例子
  - 能现场举新例 = 真懂
  - 只能背笔记里的例子 = 还没消化

### 费曼过关标准（结构化，防主观放水）

**L4/过关必须三条全满足，不是"AI觉得懂了"就算：**

```
① 说出了概念（自己的话）
② 举了笔记外的新例子
③ 回答了我至少一个 Why类/边界类 追问
```

三条全过 = 费曼过关 → 30天后复习
缺任何一条 = 不算过关 → 按表现降级排期

### 提示梯子（卡住时的引导，按顺序走，不跳级）

**触发逻辑：先正常检验 → 卡住了才逐级给提示，像过关一样一级一级来：**

```
正常检验 → 用户说不出笔记外新例子（只会背旧例） → 提示1（生活类比）
提示1给完仍无新例/沉默                           → 提示2（反向例子：什么情况下不适用？）
提示2给完仍卡                                   → 提示3（半句话开头）
提示3给完仍卡                                   → 提示4（直接讲一遍 + 记入盲区 + 3天后必回）
```

> 例 — KNN卡住：
> 提示1：「想想你到新班级，怎么判断自己该跟谁玩？看谁跟你像？」
> 提示2：「如果全班同学都跟你长得完全不一样，KNN 还管用吗？」
> 提示3：「离你最近的 K 个……？」
> 提示4：直接讲解，标记「需加强」，3天后必回（闭环，不是标完就完）

### 第三步：串联旧知识

把你新学的和之前学过的AI知识连起来，形成知识网。

> 「这个跟你上周学的线性回归比，本质区别在哪？」
> 「逻辑回归的损失函数跟之前学的MSE有什么不一样？为什么不用MSE了？」

### 第四步：一起深挖

不只是我问你答，咱俩一起往深处挖。

> 「那这个原理在UNet里是怎么体现的？」
> 「实际写代码的时候，这个参数一般设多少？」
> 「如果数据量特别少，这个方法还管用吗？」

## 四、五维检验（治"虚"）

每次复盘随机抽**一种或多种**方式检验：

| 维度 | 检验方式 | 过关标准 |
|:----:|:---------|:---------|
| **说** | 复述概念 | 不磕巴、不用笔记 |
| **用** | 现场编一个新场景例子 | 例子是新的，不是背的 |
| **联** | 跟之前学的某个知识连起来 | 能说出共同点和差异 |
| **做** | 写代码/做题验证 | 能跑通/写对 |
| **教** | 费曼教学（见五步法第二步） | 结构化三条全过 |

> **防重复（明确规则）：** 单张卡片的**最近2次 `lastTest` 不能相同**——至少隔一轮才能重复同一维度。
> 例如：上次考"说"，这次至少换"用"或"联"，下次才能再考"说"。
> 注：「教」维度与五步法第二步费曼教学是同一件事，执行时走费曼流程即可，不另设。

## 五、掌握度追踪系统

### 掌握度等级（只描述含义，具体天数看间隔规则）

| 等级 | 含义 | 判断标准 |
|:----:|:----|:---------|
| **L1 初识** | 听过概念，说不清 | 提示梯子走完仍答不上来 |
| **L2 理解** | 能用自己的话讲清楚 | 能回答"是什么"和"为什么" |
| **L3 应用** | 能举新例/写代码 | 通过"用/做"维度检验 |
| **L4 内化** | 费曼过关（三条全过） | 说+新例+答Why/边界追问 |

> 升级/降级动作：按「间隔重复」表执行（磕巴→降级3天，过关→升级30天）。
> **掌握度升级时**：AI 主动问「这个知识点你现在的一句话概括是？」，**更新 `keyInsight`**（防陈旧）。

### 盲区（治"漏"）—— 统一用卡片内 `blindSpots` 字段

- 说不清、卡壳的点 → 记入**卡片内 `blindSpots`**（不设顶层字段，避免两处打架）
- **连续2次卡壳 → 降级重学**，不硬往前赶（与间隔规则统一，无"3次"说法）
- **`blindSpots` 不为空的卡片 → 每次复盘优先抽**
- **提示梯子走完仍卡 → 记入 `blindSpots` + 3天后必回（闭环）**

### 个人易错画像（治"重复错"）

- 积累高频错误类型，形成画像：
  ```
  你的高频错误：概念混淆 40% / 公式细节 25% / 应用场景 20% / 其他 15%
  ```
- 下次复习优先抽最容易错的知识类型

## 七、复盘记录（分轻重）

### 触发条件（明确走哪个流程）

```
发现盲区 或 费曼过关（三条全过） 或 产生了有价值的新串联/深挖结论 → 深度记录
其余情况（说/用/联/做 过关）                                          → 简单更新
```

> 说明：深度记录的三条触发，任一条满足即可。"有价值的新串联/深挖"由AI判断，低门槛、不滥用——只要串联或深挖出了笔记里没有的新见解，就值得记。

### 简单复盘 —— 轻量更新

只更新状态文件，**至少3个字段**：`level`、`nextReview`、`lastTest`（`reviewCount` +1）。

### 深度复盘 —— 完整记录

在对应知识卡片末尾追加：

```
---
🔄 复盘记录（第X轮 YYYY-MM-DD）

一句话概括：XXX
检验维度：说/用/联/做/教（本次用的）
费曼过关：是/否（三条全过？）
追问点：XXX（须为Why/边界类）
串联：与XXX关联
深挖：讨论了XXX

掌握度：L2→L3（提升一级）
下次复习：YYYY-MM-DD（按间隔规则）

盲区记录：XXX（若有）
我的补充：楠楠分享了XXX看法
---
```

## 八、与学习流程的衔接

```
上午学习AI内容 → 对话中检测到学完 → 主动询问录入
    ↓
学完即录（pendingEntry 标记清除）
    ↓
晚上≥18:00 复盘（铁律：当日事当日毕；白天免打扰）
    ↓
用户晚上一开口 → 先查 nextReview 到期卡片 → 点名复习
    ↓
五步法 + 随机检验维度（最近2次不重复）→ 更新3字段 + reviewCount+1 → 计算下次复习日
    ↓
掌握度升级 → 重新问一句话概括 → 更新 keyInsight
    ↓
每周日审计：周复盘清单 → 漏的优先补 → 存 memory/ai-review-weekly.md
    ↓
blindSpots 不为空的卡片优先复习，连续2次卡壳降级重学，提示走完必回
    ↓
AI知识越滚越扎实，L3/L4 越来越多
```
