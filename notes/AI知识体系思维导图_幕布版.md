🤖 AI/ML 知识体系（2026.8.3）
- 🧠 机器学习的本质
  - 一句话：让计算机从数据中自己悟出规律做预测，不是人写规则
  - 传统编程 vs 机器学习：人告诉规则 vs 计算机发现规则
  - 本质：找一个函数 f，输入→输出
  - 核心：数据 → 规律（模型）→ 预测
- 📊 监督学习（全部通关 🎉）
  - 核心区别：分类 vs 回归
    - 分类：输出类别（是/否、猫/狗）
    - 回归：输出数值（房价、温度）
  - 🏷️ 分类算法
    - KNN（K近邻）
      - 一句话：看离你最近的K个邻居是什么类，你就是什么类
      - 算法流程：算距离 → 找K近邻 → 投票
      - K值选择：K太小过拟合，K太大欠拟合
      - 优点：简单直观；缺点：慢、维度灾难
    - 逻辑回归 👑 核心20%
      - 一句话：用Sigmoid把线性结果压到0-1，输出概率
      - 核心三步：线性组合 → Sigmoid → 概率阈值
      - 进阶①：多分类 → Softmax
      - 进阶②：正则化 L1/L2
      - 进阶③：评估指标不止准确率
      - 进阶④：类别不平衡处理
    - 决策树
      - 一句话：按特征不断二分，像玩"二十个问题"
      - 分裂标准：信息增益 / 基尼系数
      - 风险：过拟合（剪枝解决）
      - 80/20定位：快速过
    - 朴素贝叶斯
      - 一句话：贝叶斯公式 + 特征独立假设
      - "朴素"在哪：假设特征互不影响
      - 三种：高斯 / 多项式 / 伯努利
      - 典型应用：垃圾邮件分类
      - 80/20定位：快速过
    - SVM（支持向量机）👑 核心20%
      - 一句话：找最大间隔的分隔线，让两类离得最远
      - 核技巧：升维打击（低维线性不可分 → 高维可分）
      - 关键参数：C（惩罚）、核函数选择
      - 与逻辑回归区别：SVM看边界，逻辑回归看概率
    - 集成学习 👑 核心20%
      - 一句话：多个弱学习器合起来变强
      - 两大流派：Bagging（并行投票）vs Boosting（逐个纠错）
      - 核心：Boosting逐步纠错
  - 📈 回归算法
    - 线性回归
      - 一句话：找一条直线 y=ax+b 让所有点总距离最近
      - 分类 vs 回归的本质区别
      - 实操场景：韩语自媒体数据预测
      - 回归三兄弟：线性 / 岭回归(Ridge) / Lasso
- 🎯 无监督学习
  - 核心：只给数据不给答案，自己发现规律
  - 🗂️ 聚类
    - K-Means
      - 一句话：先定K个中心，把点归到最近的中心，反复迭代
      - 4步循环：选中心 → 归类 → 更新中心 → 重复
      - 两个参数：K值、初始中心
      - 坑：K要自己定、对初始值敏感
    - DBSCAN
      - 一句话：密度相连成簇，能识别噪声点
      - 和K-Means区别：不用预设K、能找任意形状、能去噪
      - 两个参数：eps（半径）、min_samples（最少点数）
      - 三种点：核心点 / 边界点 / 噪声点
  - 📉 降维
    - PCA主成分分析
      - 一句话：找方差最大的方向降维，保留主要信息
      - 算法四步：标准化 → 算协方差 → 特征值分解 → 取主成分
      - 关键：特征相关性决定主成分方向
- 🖼️ 多模态（图文分类）
  - 两大流派
    - 对比派（CLIP）— 量距离
      - 双编码器：图片→向量，文字→向量
      - 算相似度（余弦），谁近是谁
      - 零样本，不用训练
    - 融合派（BLIP/ViLBERT）— 商量
      - 特征融合：拼接 / 交叉注意力
      - 分类器 + 损失函数（交叉熵）训练
      - 效果好但要训练
  - 关键：双编码器提特征 = 所有图文分类的命根子
